Firebase Setup – Admin Dashboard

Connect Firestore so the admin dashboard shows live data.

1. Deploy Firestore Rules

Deploy the security rules to your Firebase project:

firebase deploy --only firestore

Or copy the contents of firestore.rules into Firebase Console → Firestore → Rules and publish.

2. Create Admin User

  • Go to Firebase Console → Authentication → Users
  • Add a user with email admin@kotapal.com and your chosen password
  • Or use the main app’s Sign Up form to register admin@kotapal.com

3. Enable Firestore

  • Go to Firebase Console → Firestore Database
  • Create a database if needed (start in production or test mode)
  • The users and blocks collections are created automatically when users sign up and create blocks

4. Admin Login

Open admin.html, sign in with admin@kotapal.com and your password. The dashboard will load live data from Firestore.
